How to read this table
  • One row = one group of identical rollers (one colour in the drawing), in flow order.
  • ① Pitch = centre-to-centre between rollers inside the row. ② To next row = centre of this row's last roller → centre of the next row's first roller (a belt counts from its edge). The last row has no ②.
  • Red ② = this row overlaps the next one. — = not used for this type (a belt has a length, rollers have qty / Ø / pitch).
  • ＋ inserts a copy after the row. Any change pushes the following rows to the right. ◆ under a type = a sensor or room wall is tied to that row.
  • Drive rule: glass touching an INV roller or belt moves at room speed; otherwise touching a chain / chain head / normal roller → base speed; on free rollers only it keeps the speed it had.

    Logic used & open points
    • CONFIRMEDGₛ = glass length counted by the slow encoder (1 p = 0.3125 in) from Entry ON to OFF. The workbook tables that use L/0.265 are wrong (selectable in Parameters for comparison).
    • CONFIRMEDSource: Siemens ladder printout FC0/FC1/FC2–FC5/FC10/FC12 (AFT SP MIR-SB03 book, p.16–100). The program doesn't know Single/Batch. If the 1st sheet is ≤ 170 p it waits 30 p for another (the 2nd sheet is not length-checked); max 3 sheets — at the 3rd OFF it closes. L = 1st ON → last OFF incl. gaps (with 3 sheets the PLC adds L3 twice and never L2 — harmless for equal sheets).
    • CONFIRMEDSpeed-up when the slow counter (from the 1st front edge) reaches A + L − ⅓·Llast; the command follows 150 ms later (T20/T40). X = 1110 − L + ⅔·L₁ − K, with K from the 1st sheet length (top table steps at 340, base at 320); X is counted in high pulses (0.265 in) from the command. Single sheet: A + ⅔L and 1110 − ⅓L − K. Two counters: a 3rd load arriving while both wait is not tracked.
    • CONFIRMEDRun-up fault: high command but < 100 high p within T12 (base) / T32 (top). Retardation fault: base command but high-speed feedback after T13.
    • CHECK ONLINEThe DB values in the printout are offline start values, not what runs in the CPU (DB says Charge Too Long 450 p = 140.6 in, yet 144 in glass runs every day → 470 used). Still to read online: A (DB9/DB10.DBW140/142: offline 150, supplier 146), run-up times (DB8.DBW24 = 3.0 s base, DBW64 = 1.5 s top), and DBW144–148 ("Puls lifting/lowering", a 2nd path that can end high speed — not in the printout, not simulated).
    • CONFIRMEDYellow = chain conveyor (base only), pink = chain head, grey = free roller, blue = new free roller, purple = INV roller (2-speed, top room only: Mitsubishi inverter 33M1 switched by FC11 on the same PLC command as the Lenze servo — high with Q20.1, back to low at setpoint X / Q20.0).
    • CONFIRMEDDesigned for one load at high speed at a time; an overlap is logged (possible bug). Largest load 470 p — longer stops the line immediately (Charge Too Long).
    • CONFIRMEDGap inside a batch 2 in, between loads 10 in (= 32 p, only 2 p above the 30 p merge window). Speed change itself = instant (ramp 0 s).
    • ASSUMEDGlass touching both a 2-speed element and a chain follows the 2-speed element (Parameters → Glass physics). This decides whether the last sheet of the previous load, still half on belt 2, is yanked into the sheet ahead when the next load speeds up.
    • FINDING3-in-flow batches (24×36, 42×32, 48×36): with the ladder formula (speed-up at A + L − ⅓·Llast) the 3rd sheet is already on the INV rollers at speed-up → 100 % coated at high speed in both rooms. (The earlier A + ⅔L formula left it on the free rollers in the base room → ~⅓ thick film; that finding is withdrawn.)
    • FINDINGTop room, B 42×32 · 2×3 with 10 in between loads: the next load at high speed touches the last sheet of the previous load near the end of belt 2 (~1 m before Exit), which is still at base speed. Depends on the layout estimates — check on the line.
    • ASSUMEDLayout dimensions are first estimates from position_sensor.pdf — correct them in the Layout editor. Base-room Exit sensor is a placeholder.
    • EDGESingle sheet L ≥ 3(A+1) p (441 p = 137.8 in with A 146; 141.6 in with A 150): the setpoint A + L − ⌊L/3⌋ is below L, i.e. reached before the tail clears Entry. The PLC only compares after the measurement ends (Entry OFF), so the speed-up comes right then — later than the formula (marked * in the table). 144 in: setpoint 454 p, L known at 461 p → 7 p ≈ 56 mm late, still 100 % coated at high speed. Batches never: they close 30 p after the last OFF, and A − ⌊Llast/3⌋ ≥ 90 p.
